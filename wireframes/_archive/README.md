# Архів стилів вайрфреймів

**Не підключено жодною сторінкою.** З уроку 07 (крок 5) усі 28 сторінок `wireframes/`
збираються з [`ui/kit.css`](../../ui/kit.css) + [`_chrome.css`](../_chrome.css).

Тут лежать шари, з яких кіт було витягнуто, — `_wireframe.css` (сірий каркас), `_panel.css`
(мова «Панель») і `_parts/*.css` (екранні правила змістового й геометричного проходів) разом
із протоколами `_parts/_BRIEF.md` і `_parts/_GEOMETRY.md`. Коментарі в них — обґрунтування
значень, на які посилаються `DESIGN.md`, `concept/concept.md` і журнали. Правити тут немає
сенсу: зміни вигляду йдуть у кіт за правилом «залишаємо» (CLAUDE.md §19).
