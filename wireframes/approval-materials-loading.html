Zones

Head. The claim names the job: the buyer chose, the budget holder approves, so whatever this page shows will be retold upward (O6 definition). The ghost CTA points to the R3 primary carrier, the forwardable solution page: this library complements that page, it does not replace it (sitemap.md §6.4, the resolved [Г1] debt).

Why ungated. O6 is ungated by default: a gate adds friction with no job underneath (jtbd.md §8.3). The same section carries the two E2 rules: one canonical value per figure, a date on every artifact.

Artifact list. Structure real, contents honest. The forwardable summary and the compliance mapping resolve to existing pages; the specification sheet and the outcome case stay declared slots marked [TBD — no source]: a figure and a client for a fictional brand would be invented facts (sitemap.md O5 fillable-proof table). The accreditation overview names categories only; real companies are never named as Asterra's partners (brief §6.1).

No download controls. Download mechanics is a build-stage decision, so artifacts appear as rows and page links; nothing promises a file the wireframe cannot stand behind.

Fallback tail. aFallback made permanent: identical in all four states, offering the forwardable solution page and the expert conversation. Visible on base too, because the solution page is the job's primary carrier, not a consolation.

Wireframe stage

Grayscale, no brand colour, photography, icons, shadows, gradients, web fonts or motion. Copy is real domain content: no invented product, figure, certification or client.
